# وصل — تواصل محلي عبر Bluetooth Classic

هذا مشروع Flutter فعلي كبداية قابلة للبناء، وليس واجهة فقط: يحتوي على تطبيق Flutter وقناة Android Native تستخدم RFCOMM Bluetooth Classic، وإنشاء غرفة برمز متغير، واكتشاف الأجهزة القريبة، والتحقق من الرمز عند الاتصال، وتمرير الرسائل والملفات عبر جهاز المنشئ. رابط الدعم وحده يفتح الرابط `https://wsend.co/967737414884`.

## المتطلبات
- Flutter حديث (يفضل Flutter 3.24 أو أحدث) و Android Studio / Android SDK.
- أجهزة Android فعلية مع Bluetooth Classic. المحاكي غالباً لا يوفر اتصال بلوتوث فعلياً.
- لا توجد خوادم أو إنترنت مطلوب للمحادثات.

## تشغيل المشروع
1. فك ضغط الملف.
2. افتح مجلد `Bluetooth_Community` في Android Studio أو افتحه من الطرفية.
3. نفّذ:
   ```bash
   flutter pub get
   flutter create . --platforms=android
   flutter run
   ```
   إذا أنشأ `flutter create .` ملفات Android افتراضية جديدة، احتفظ بملف `MainActivity.kt` و`AndroidManifest.xml` وملفات Gradle المخصصة الموجودة بالمشروع.
4. على جهاز المنشئ اضغط «إنشاء غرفة بلوتوث». امنح الأذونات، وشغّل Bluetooth واجعل الجهاز قابلاً للاكتشاف إذا طلب النظام ذلك.
5. على جهاز المشارك اضغط «البحث عن أجهزة قريبة»، اختر جهاز المنشئ، أدخل رمز الغرفة ثم «دخول الغرفة».
6. اسمح بطلب الاقتران/الاتصال في Android عند ظهوره.

## ملاحظات مهمة وحدود النسخة
- الاتصال الأساسي والمراسلات والملفات (حتى 4MB) عبر Bluetooth Classic فقط. لا يستخدم التطبيق الإنترنت للمحادثات. زر الدعم يفتح واتساب فقط.
- الغرفة بنمط مركز/أطراف: المنشئ يمرر رسائل الأعضاء لبقية الأعضاء. ينبغي أن يبقى تطبيق المنشئ مفتوحاً واتصاله فعالاً؛ Android قد يوقف النشاط في الخلفية.
- أجهزة Bluetooth Classic عادةً لا تسمح لعدد غير محدود من الاتصالات المتزامنة. عدد الأعضاء الفعلي يعتمد على الهاتف والشركة المصنّعة.
- البحث عن الأجهزة قد يتطلب جعل جهاز المنشئ قابلاً للاكتشاف من إعدادات Android. رمز الغرفة لا يظهر تلقائياً في نتائج البحث؛ يجب اختيار جهاز المنشئ ثم إدخال الرمز.
- هذه النسخة لا تنفذ تشفيراً طرفياً أو تخزيناً دائماً للمحادثات أو إشعارات بالخلفية. لا تستخدمها للمعلومات الحساسة قبل إضافة مراجعة أمنية واختبارات فعلية.
- الملفات المستلمة تحفظ داخل مجلد ملفات التطبيق (Downloads الخاص بالتطبيق)، وليس بالضرورة مجلد التنزيلات العام.
- لم يتم بناء APK أو اختباره على أجهزة فعلية داخل هذه البيئة. اختبر الاتصال على جهازين مختلفين قبل الاعتماد عليه في بيئة عمل.
